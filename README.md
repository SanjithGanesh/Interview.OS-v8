# Interview.OS (v8)

Interview.OS is my job-hunt command center — built to turn a messy application workflow into a clean, trackable system. It’s an early-access app focused on helping you apply smarter, stay organized, and follow up consistently, with a UI that’s fast, minimal, and actually enjoyable to use.

## What it does
- **Pipeline tracking**: Manage jobs across stages (Wishlist → Applied → Interview → Offer/Closed) with clear status visibility.
- **Add jobs quickly**: Capture core job info (company, role, link, notes) without friction.
- **Follow-ups & reminders**: Schedule follow-up dates so nothing slips through the cracks.
- **Interview scheduling**: Track interview rounds, dates, and next steps in one place.
- **Job details view**: Open a dedicated details modal to see everything tied to one job.
- **Templates & messaging support**: Built to support follow-up messaging workflows (email/LinkedIn style templates).
- **Analytics**: Usage-style tracking to understand what’s happening in the pipeline and where drop-offs happen.
- **Feedback**: A feedback page to capture improvements, friction, and iteration notes.

## Pages included
- **Today**: Your “what needs attention now” view (reminders, follow-ups, upcoming items).
- **Pipeline**: Main job tracking board across stages.
- **Prep**: Interview preparation workspace.
- **Usage**: Basic usage/interaction insights.
- **Analytics**: Simple metrics view for tracking progress.
- **Feedback**: Submit feedback and log improvements.
- **Permissions**: Any access/permission related UI handling.

## UI / UX goals
- Clean, modern layout with fast navigation
- Modal-first interactions for speed (Add Job, Follow-up, Interview, Job Details)
- Light + dark mode friendly styling
- Built to be “daily usable” without feeling heavy

## Tech (repo snapshot)
- React + TypeScript
- Component-driven structure (`src/components`, `src/pages`, `src/hooks`, `src/ui`)
- App-level analytics context/provider for tracking usage events

## Status
This repo is a **snapshot of Interview.OS v8** (early access). Future iterations may include deeper interview prep (audio/video), smarter personalization, and expanded automation — while keeping the workflow simple and fast.
